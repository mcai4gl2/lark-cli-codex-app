## Slack Reaction Commands

### Problem / Goal
- Implement the optional Slack reaction commands from Phase 3 of `slack-migration.md`.
- Keep command output compact and use Docker-based Go formatting, tests, and build verification.

### Problems Encountered
- Docker build requires marking `/work` as a git safe directory inside the disposable container so Go VCS stamping can read repository metadata.

### Key Design Decisions
- Mirrored the existing Lark command shape with `slack msg react`, `slack msg react list`, and `slack msg react remove`.
- Used Slack message coordinates directly: `--channel` plus `--ts`.
- Normalized reaction names by trimming surrounding colons so both `eyes` and `:eyes:` send Slack the expected `name`.

### Solution / Implementation
- Added Slack Web API client support for `reactions.add`, `reactions.get`, and `reactions.remove`.
- Added compact reaction output types for mutation results and reaction listing.
- Added CLI wiring and flags for add, list, and remove reaction commands.
- Updated Phase 3 in `slack-migration.md` to mark reactions complete and document required scopes.
