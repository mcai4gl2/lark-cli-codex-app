- Add filesystem-backed Slack audit logs, explicit Markdown memory files, prompt context injection, gateway wiring, config/CLI support, and user documentation.

- The initial gateway observer implementation needed a nil-store guard so zero-value observers cannot panic.
- The first plain Docker build failed on Go VCS stamping because the mounted repository was not marked as a safe Git directory; rerunning the build with `git config --global --add safe.directory /work` resolved it.

- Added a dedicated `internal/slackmemory` package for path layout, audit records, Markdown reads/appends, and prompt-context assembly.
